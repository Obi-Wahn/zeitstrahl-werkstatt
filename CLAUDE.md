# Arbeitsweise in diesem Repository

## Ablauf für Änderungen

Für jede Änderung gilt diese Reihenfolge:

1. **Vorschlag:** Beschreiben, was geändert oder gebaut werden soll.
2. **Fragen:** Fragen, ob die Änderung umgesetzt werden soll, und auf die Antwort warten.
3. **Bauen:** Erst nach ausdrücklicher Zustimmung umsetzen, zunächst nur lokal. Nichts committen, nichts pushen.
4. **Bestätigung abwarten:** Die Änderung wird geprüft. Erst wenn ausdrücklich dazu aufgefordert wird, einen Pull Request zu erstellen, geht es weiter.
5. **Commit und PR:** Dann auf einem eigenen Branch committen, pushen und den Pull Request erstellen.

Niemals direkt auf `main` committen oder pushen.
